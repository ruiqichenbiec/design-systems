# 交互动态 · 1.3.0（规格）

用户要求（2026-09-30）：继续改进交互中的动态表现，并制作一个全嵌入的单页 HTML 演示页。确认：演示页内嵌 720p 压缩宣传片；加入可选交互声音，默认关闭。

## 动作论点

- **焦点时刻**：演示页片头 ENTER。快门在按钮上合上，片头以光圈收拢到按钮，下一幕的光圈舞台随弹簧张开（序曲 → 开幕）。
- **连续性**：浮层从触发按钮张开、退回按钮；灯箱照片从缩略图飞入并显影；表格排序、关键词增删用 FLIP；底片带 1:1 跟手并带惯性吸附；照片墙运镜承接速度。
- **反馈**：按钮填充从指针处张开；拨杆、勾选、刻度针、计数翻片、取景框都用同一组弹簧；可选音效只在有意义的动作上响。
- **预算**：所有弹簧共用一个 rAF，静止即停；GPU 场景仍按输入或可见性绘制；减少动态时全部直接落位、无持续循环。

## 运动核心 `Overture.motion`（三个语法各一个原语）

| 语法 | 原语 | 规则 |
| --- | --- | --- |
| 开幕／遮挡 | `iris(el, {open, origin, shape})` | 圆形光圈以触发点为圆心；另有快门、展开两种形状。退出约为进入的 0.6 倍时长并加速离开；中途打断从当前裁切继续 |
| 聚焦／显影 | `develop(el)`、`flip()`、`count()` | 从过曝黑白显影到正常；重排从旧位置移到新位置；数字按方向翻片 |
| 张力／凝住 | `spring({preset})` | 阻尼谐振子解析解；重设目标时保留位置与速度；`freeze()` 冻结在当前位移与速度。预设 snap（控件，340 ms 静止）、settle（相纸与胶片，570 ms）、stage（运镜与开幕，830 ms；位置进入 0.5 % 约 790 ms）、resonance（丝绸回荡，周期 0.53 s）、swing（图钉相纸摆动，周期 1.05 s） |

CSS 用同一弹簧生成的 `linear()` 缓动（`--ov-spring`、`--ov-settle`）；不支持 `linear()` 的浏览器退回普通缓动。

`Overture.sound`：默认关闭。快门、齿轮、拨杆、纸、落桌、丝绸、光圈、切光八种 Web Audio 合成声音，按元素水平位置左右声像；不自动播放，不依赖音频文件。

## 组件（摘要）

- 开幕：Dialog / Drawer / CommandPalette / Popover / Toast 有进入和退出（含 Escape、遮罩、按钮、保存）；Accordion 展开收起；ApertureStage 的 ENTER、滑杆与滚动联动走弹簧；CurtainTransition 改为左右两幅幕布合拢再分开；主题切换以按钮为圆心的光圈（View Transitions）。
- 显影：DevelopImage 的光斑带惯性跟随、进出时半径张缩，选中时显影液从点击处漫开；FocusGallery 灯箱 FLIP；EditorialTable、TagInput FLIP；Pagination、Stepper、照片墙计数翻片；StageTabs 取景框弹簧移动并按方向展开面板。
- 共振：SilkResonance 松手后按张力回荡，凝住冻结回荡中途；Range 刻度针模拟表针；Switch 拨杆、Check 勾选笔画、ChoiceGroup 选中压印从指针处张开；Progress 弹簧推进；FilmCanister 两端橡皮筋回弹、相纸落桌回弹；ContactSheet 底片 1:1 拖动并按速度吸附到最近一帧；照片墙与追光墙上的相纸被指针拂过时绕图钉摆动。

## 保持不变（用户已确认）

- FlashlightFocus：三格滚轮、六个固定灯位、首尾释放。前两格只转动准星（对焦环），灯位不动。
  - 2026-09-30 用户追加：“V 那部分的两个每次滚动生效的时候加一点动画，不要直接换”。第三格起光束沿 settle 弹簧移到下一张照片中心（约 570 ms，途中收窄到 70 %、到达后张开），只在六个中心停留；取代先前的“切光”。
- PinnedPhotoWall：两格滚轮、半步反馈、约 780 ms 运镜落位、首尾释放。运镜改由 stage 弹簧驱动，连续输入承接速度。
- 减少动态（包括 Windows 关闭“显示动画”时浏览器报告的减少动态）：两面墙都不再直接跳换，改为 420 ms 淡出淡入 `dissolve()`，不做位移。单文件演示页默认完整动态，页头可切换。
- ContactSheet：4.8 s 自动走片、整张相纸换片、悬停／聚焦／离屏／减少动态时停走。

## 单文件演示页

`dist/overture-showcase.html`：CSS、JS、字体、照片（WebP）、three.js 与图形引擎（gzip）、720p 宣传片全部内嵌；双击以 file:// 打开可用，GPU 依次尝试 WebGPU、WebGL2，失败时用静态图。片头 → 开幕 → 显影 → 共振 → 夜场 → 追光 → 动势 → 尾声。

# 光的观看方式 · 1.1.2

保留三张原始参考中的暖黑、象牙印纸、朱红缝线、摄影颗粒与编辑式排版。新增组件使用现有照片，原生 HTML/CSS/JS，无新增运行依赖。

## 体验与验收

- **追光取景 FlashlightFocus**：整面六张照片墙固定可见；每三格滚轮切换一张，前两格保持灯位并显示计数，第三格直接切至下一张中心，只使用六个固定位置。反向输入重新计数，首尾向外滚动释放页面。开度滑块独立保留；按钮、方向键和一次触屏滑动逐张切换。支持固定高度容器与一屏整页模式。
- **线索照片墙 PinnedPhotoWall**：中央大光束固定；普通鼠标每两格滚轮前进或后退一张，第一格显示半步反馈，第二格用 780 ms 运镜落位。小幅触控板输入累积为两格；反向输入清除旧方向的半步，单个大事件最多计一格。首尾向外滚动正常离开，按钮/键盘/触屏滑动可直接逐张切换；减少动态时直接落位。
- **自动接触印相 ContactSheet**：每 4.8 秒走片；主照片、相纸边框、题名与套准标记作为同一张实体纸共同移出/移入，底片带的齿孔和边框一同移动。循环末尾无反向穿越。显式暂停/继续、上/下一张、拖动和键盘保留；手动选择不会抢走焦点。不可见、页面隐藏、减少动态时停止自动轮播。
- **操作语言**：快门确认按钮、移动取景框标签、曝光刻度尺、机械拨杆、计数翻片、取景输入框和选中压印使用一致的光/框/纸行为。原生语义、键盘和禁用态保留。提供一个可操作的整合控制台，变化影响真实画面。

## 动效预算

焦点时刻：三格滚轮让光束在完整照片墙的六个固定灯位间切换，与两格一张的固定追光形成不同观看节奏。连续性：整张相纸共同换位，齿孔与底片一起走片。反馈：半步、当前照片与进度就地可见。两块大型画布按需绘制 WebGPU / WebGL 2 光照遮罩，失败时 CSS 光照仍工作；相机仅在 780 ms 运镜期间使用 rAF。小控件使用 CSS / WAAPI，不引入动画库。连续输入从当前相机位置接替动画，无累积定时器或监听器。

## 验证

相机路径边界与连续性单元测试；构建及资源检查；桌面/窄屏浏览器检查两种光照、原生滚动、自动循环、暂停、方向键、缩减动效及图形降级；重新生成 ds-viewer 并检查组件卡。
