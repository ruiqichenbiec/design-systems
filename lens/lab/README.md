# Lens · 透镜实验室

一个无依赖、可离线运行的网页组件演示。支持中英文切换，桌面与手机自适应。默认使用“厚润 / Thick”材质。

## 打开

双击随附的 `lens.html`（中文入口）或 `lens-en.html`（英文入口），即可离线使用。两个版本都可用右上角的“中文 / EN”切换，无需安装依赖。语言切换保留当前组件状态，语言偏好会在浏览器允许时记住。开发版可用 `?lang=zh` 和 `?lang=en` 指定语言。

开发版在当前目录运行：

```sh
npm start
```

然后打开 http://127.0.0.1:4173 。使用 `PORT` 环境变量可调整端口。

```sh
npm run check
npm test
npm run build
```

`build.mjs` 会在上一层目录生成包含全部 CSS、脚本、双语文案和图标的两个实验室单文件网页，以及 `lens-showcase.html` / `lens-showcase-en.html` 两个完整展示页。

## 设计系统与真实控件音效

`design-system/` 是独立、无运行时依赖的 ESM 包。打开 `http://127.0.0.1:4173/design-system/index.html` 可体验双语组件目录；`design-system/examples/basic.html` 是独立接入示例。完整 API、主题覆盖和扩展方式见 [设计系统使用说明](design-system/README.md)，设计规则见 [设计契约](design-system/DESIGN.md)。

系统包含 18 类公共组件工厂、CSS / JSON 设计变量、厚润等材质预设、弹性手势、13 种原创短音效、透镜纸面摩擦音和 TypeScript 类型。新增的横向透镜卡片列表可组合图标、文字及现有控件，支持原生滚动、吸附、前后按钮和键盘导航。复制整个 `design-system/` 文件夹即可嵌入其他页面，也可通过本地 npm 包导入。原网页共用同一份渲染、物理和声音实现。核心元素归属、透镜组件复用及当前待对齐项见 [系统范围与复用规则](design-system/SCOPE.md)。

真实开关、胶囊、按钮、滑杆、步进器、搜索、通知和透镜手势均已接入声音。材质调节区提供静音与音量设置，默认音量 28%，偏好自动保存。音频只在用户操作后启动；连续输入和滑杆会节流。静音立即取消正在播放和等待中的提示音；音频不可用时保留视觉与键盘反馈。

## 可以体验什么

完整展示位于 `design-system/examples/optics.html`，包含材质透镜、基础控件、光学交互及数据展示。折线、玻璃柱形、环形图共用示例数据；周期和分类选择联动更新图表及表格，表格支持搜索、排序、分页和记录详情。展示页提供中英文切换、声音试听与音量设置；详见 [SHOWCASE.md](design-system/SHOWCASE.md)。

新增 [光学交互](design-system/INTERACTIONS.md) 基于设计系统 1.0.0 恢复基线：进度条光纤波动与完成变色、透明拖放选择与凹凸落点、二维普通滑块 / 放大透镜、选项胶囊的边缘流光。实验室、组件目录和两个离线 HTML 共用同一实现；集中预览入口为 `design-system/examples/optics.html`。

- 玻璃按钮、分段选择、控制中心、开关、滑杆、底部导航和弹出菜单。
- “组件”页签中包含可搜索的组件库：选项胶囊、时长步进器、通知卡片及操作按钮；状态相互关联，可收起和恢复通知。
- 按住卡片或玻璃按钮可拖动；随速度产生方向性拉伸与边缘滞后，松手回弹。亮度滑块、开关、分段选择也支持拖动，数值和选择正常提交。
- 独立“流动弹性”调节；键盘继续可用。背景色带具有柔和曲面光和层间遮蔽。
- 三种材质预设，独立调整折射、雾化、边缘色散。
- 四种背景；网格背景能清楚显示透镜边缘的弯曲。
- 透镜模式：鼠标或触摸拖动；方向键移动，Home 回到中央。
- 透镜卡片列表：横向触控板／触摸滚动与吸附，前后按钮、方向键和 Home / End 导航；卡片内可组合滑杆、进度和按钮，嵌套控件保留自己的键盘与指针操作。
- 普通毛玻璃对比、降低透明度、暂停背景动画。
- 复制当前材质 JSON；剪贴板受限时下载 JSON。
- 键盘焦点、菜单 Escape 与方向键、减弱动态效果偏好。
- 专注开关的轨道和滑钮按顺序在 GPU 内绘制，绿色轨道不会覆盖滑钮；滑钮沿轨道压缩拉伸，保持在内边距内。支持点击、拖动、空格和左右方向键。
- 选项胶囊用勾选图标、淡色玻璃和细描边共同表达选中，手机端保留提示。数值轻滚、收藏心形填充与弹跳、确认按钮成功态、通知收起和恢复、菜单浮现、重置旋转与复制成功勾选提供对应反馈。

无线网络、蓝牙等是页面内组件状态示例，不会改变设备设置。收藏和参数仅保留在当前页面会话中。

## 光学实现

`glass.js` 导出 `GlassRenderer`：

```js
import { GlassRenderer } from './glass.js';

const renderer = new GlassRenderer(canvasElement, stageElement, {
  refraction: 0.90,
  blur: 0.24,
  dispersion: 0.65,
  motion: true,
  scene: 'aurora'
});

// stage 内的语义化 HTML 元素以 data-glass 标记，圆角从 CSS 读取。
// <div class="glass" data-glass="panel">可访问的 HTML 内容</div>
renderer.set({ refraction: 0.8 });
// 删除整个组件时释放观察器和 GPU 资源：
renderer.destroy();
```

背景图案与文字先绘制为纹理，进入 WebGL2 帧缓冲。每个玻璃圆角矩形用有符号距离场计算边缘法线，以 Snell 折射模型偏移真实背景采样，并加入 RGB 色散、九点雾化、Fresnel 近似边缘光和跟随指针的高光。两个 RGBA 帧缓冲交替合成，后绘制的玻璃可以采样已有玻璃层。

`jelly-physics.js` 提供限制时间步长的阻尼弹簧；`jelly.js` 处理指针捕获、中断、回弹和语义控件提交。运动方向上的拉伸与垂直方向压缩保持面积，Shader 使用包含父级变换的逆矩阵及弹簧弯曲量，轮廓、折射与高光随同一形状变化。手势结束后停止物理循环。

玻璃中央降低白色覆盖，保留背景颜色。反光由低强度的宽面环境反射、细窄的方向高光及暗部边缘共同组成。背景曲面的光照与层间阴影只在切换场景或改变尺寸时生成。

运行 `npm test` 检查弹簧在不同帧率下的收敛、拖动中断、面积保持、移动边界、开关拉伸边界，以及双语文案覆盖与插值。测试命令使用 Node.js 24 的无子进程隔离模式，适合受限环境。

`i18n.js` 集中管理可见文案与无障碍名称。选择值使用固定 ID，切换语言不会把标签文字误作业务状态。材质的选中着色和透明度同步传入 Shader，通知淡出时文字和玻璃同时消失。每个玻璃控件独立声明定位基准，避免继承父卡片的居中偏移。

语义化 DOM 负责文本、焦点和输入；GPU 只负责材质。背景动画停止、离开视口或标签页隐藏时减少渲染，设备像素比上限 1.75。WebGL 不可用或上下文丢失时，界面降级为明确标注的 CSS 毛玻璃，并继续响应交互。

## 边界

折射覆盖本演示的画布背景和玻璃材质层，不会自动截取或折射任意第三方 DOM、iframe 或视频。要用于其他页面，需要将待折射内容提供为渲染纹理。

不支持 WebGL2 的环境只提供 CSS 毛玻璃兼容效果。系统开启“减弱动态效果”时默认暂停背景动画，手势的变形幅度减弱并增加阻尼；用户主动调整“流动弹性”后使用选定强度。底部导航是组件示例，切换总览、通透材质、收藏状态，或聚焦材质调节。

参考：[MDN · WebGL framebufferTexture2D](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/framebufferTexture2D)。
