# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
在网页中做出可真实操作的玻璃材质 UI 组件：实时折射、液体形变与光。

## Brand Commitments
方向：厚润的玻璃透镜、液体般的弹性与方向性高光。

## Implementation Assumptions
采用无依赖 HTML、CSS、JavaScript 与 WebGL2，交付本地网页和可复用渲染模块。中英文界面，默认厚润材质。所有示例状态只影响网页本身。

## Scope
按钮、分段选择、开关、滑杆、弹出菜单、底部导航；材质参数、动态背景、毛玻璃对照；移动端和键盘可用。没有账户、后端或外部资源依赖。

用户后续明确要求：调节和按住拖动时产生果冻般的流动变形；背景分层色带增加立体感；增加组件；弱化夸张、集中于边缘的光影。组件库增加搜索框、选项胶囊、步进器、可收起通知和操作按钮。光学与弹性共同响应手势。

双语版本须覆盖静态文案、动态状态、提示、输入占位符和无障碍名称，并在切换时保留当前选择。默认及重置为厚润（90% 折射、24% 雾化、65% 色散）。专注滑钮须正确覆盖轨道并在变形时保持在轨道内。胶囊选中态同时提供符号和颜色提示，所有短时动画尊重减弱动态效果偏好。

真实控件操作提供轻量交互音效，并有静音、音量和偏好记忆。默认不自动发声；声音不可用不得阻断控件。设计系统作为独立原生 Web 包保存，包含组件工厂、统一设计变量、材质、弹性、声音、TypeScript 类型、双语组件目录及可运行的独立示例。新增组件与声音通过公开注册接口扩展，现有网页与复用包共享实现。
